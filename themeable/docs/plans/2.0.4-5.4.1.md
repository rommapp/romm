# RomM-Themeable 2.0.4-5.4.1 Development Plan

*RomM's README back at the root*

Oct 28, 2026 · Stealthx3

The fork replaced RomM's root `README.md` with its own landing page, so every upstream change to that file conflicted, including in rommapp/romm#5308. Resolving it on `main` would mean merging unreleased upstream code.

## Tasks

1. **Move the landing page.** The fork's README moves to `.github/README.md`, which GitHub shows in place of the root README, with its links adjusted. The root `README.md` is RomM's 5.4.1 README again, byte for byte, so upstream's changes to it merge cleanly.
2. **Workflow and rules.** The upstream release workflow only keeps `main`'s `docker-compose.yml` on a conflict. `GUIDELINES.md` and `themeable/README.md` name `.github/README.md` as the module's and the root README as RomM's.
3. **A test** fails if the root README mentions romm-themeable, or if a relative link in `.github/README.md` points at a missing file.

`.github/README.md` must not be part of a pull request to RomM, since it would replace RomM's front page.

## Version

`themeable/package.json` becomes `2.0.4`.
