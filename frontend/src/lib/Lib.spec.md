# Lib

The v2 primitive library: the R* components every view builds on, each with its Storybook story, themed only through design tokens.

## folded

- data/**: tables, sort headers and other data display primitives, one folder per component
- forms/**: form controls, one folder per component
- menus/**: menus, one folder per component
- overlays/**: dialogs, carousels and other overlays, one folder per component
- primitives/**: base primitives, one folder per component
